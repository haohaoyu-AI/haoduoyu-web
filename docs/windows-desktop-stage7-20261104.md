## 选择与来源

网站已有周/月日历，桌面只有单日日期选择；文章已有流水线和只读对账作为可用路径，因此本轮先补待办历史。正常无登录只读复核公开静态资料：OpenAPI 836155 B、SHA256 `db16b231b41c6012c1cf7b1c2c2f8bdcf447924a791b2ce5766f0263e3ce698d`，与已知 `c30a8a956715b6ea809db4b87c0f4fcddf8f61de` 相同；线上 `todoCalendar`、`createTodoMonthLoader`、`todoMonthSeed` 函数与该源逐字节一致。普通日待办接口未在该 OpenAPI paths 中枚举，本轮以既有桌面日读、现行网页调用和已知源真实 Worker 契约核实，不虚构月汇总端点，也不据此证明生产精确 Git SHA。

实际接口仍是 `GET /api/v1/todos?date=YYYY-MM-DD`。响应只有 date、today、completed_mode、preferences_version、items，没有 scope、read_revision 或 can_edit；items 为全部活动待办，隐藏已完成只影响日常展示。合法日期为0001–9999年。

## 本轮能力与口径

- 原生自然周（周一至周日，跨月）与月份日历、前后导航、月份跳转、北京时间今天、全部/已完成/未完成筛选、每日最多四项预览及余项。最小/最大日期周会裁到可表示边界，不越界生成年份。
- 点击日期只回到原单日待办，沿用现有创建、完成、软删和 CAS 操作；日历不新增批量写协议。
- 即时离线展示当前分区已知资料和本机队列投影。完整空日、缺日、局部缓存和仅有待同步请求的日期分开；缺日不能算零任务，日常 hide 偏好不改变历史统计。
- 明确区分范围总数、筛选数量和当前已知条目小计。所有汇总均为本机视图，不把 Queued/Unknown 当服务端确认。隐藏的未决删除仍计未决；无日期证据的操作不猜今天，已知窗外请求不误算进当前范围。
- 只读范围副本注明筛选与来源，不称完整原始备份；切账户清空视图与筛选，原始缓存、草稿和请求不因导航或筛选改变。

## 刷新与预算

显式刷新当前范围，最多31个日期、累计8MiB网络JSON、12MiB本机编码缓存及5000行。网络单日仍限1MiB，本机单日解析可到4MiB以容纳原合法Unicode被缓存转义后的表示；不抬高其他网络接口预算。每一天必须真实读取并验证日期、Today、偏好水位、UUID/版本/布尔值、来源时间和可选模板字段，同UUID不能跨日期重复。

源 `storage.mjs` 的应用写入与全局 revision 同批递增，因此加载器在日期前后读取全局修订号，并核对前后 service scope；期间任一应用数据变化、跨北京时间午夜、429、坏日、取消、预算或身份失败都不返回待提交批次。只有全部成功，UI 再核对当前身份/范围/取消后一次 CacheBatch 提交。元数据 `_local_todo_history` 保留 service scope、批次、范围、全局修订号与观察时间，不往服务原 DTO 伪造字段。

全局修订能检测应用数据 ABA，但环境 owner/scope 配置不由应用 storage 提交；缺少逐请求原子 expected-scope 前提的既有外部配置竞态仍存在，不声称消除所有身份配置 ABA。不同历史日可来自多次读取，界面会注明，不能混称同一时刻的服务端快照。未准备日期仍需按范围显式读取，不做无界多月抓取。
