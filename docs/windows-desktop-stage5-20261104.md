## 本轮选择与边界

网站 `web/pages/articles.mjs`、`web/pages/article-form.mjs` 和 `src/article-pipeline-fields.mjs` 已支持槽位、作者、配图者、存稿日期、系列号、字数/小标题/图数、生产目录、草稿凭证及完成时间。原生 0.4.0 的 `Editors.cs` 只暴露基础字段，虽然提交时保留隐藏流水线字段，用户不能独立录入或查看这些资料。本轮优先补齐这一业务闭环。

本轮不增加待核清单的远端勾选写入、平台登录/采数或旧统计无 CAS 写表单。自动更新继续缺少可信签名、稳定发布与撤回契约，不接入自动下载或执行。此前 artifact 下载 HTTP403 的停止边界不变，不重试、不换工具或路线。

## 仍存在的业务差距

- 网站文章发布对账、编号重复/内部缺号候选和更完整筛选尚无原生入口；即便以后增加，也须核实 `complete=true` 和全部账户/分页，不能把编号候选当实际漏产。
- 待办周/月历史视图尚未实现；已有单日日期选择和本机检索不能冒充周月摘要。未缓存日期不能算零任务。
- 待核清单目前只读，不会伪装成已逐项完成或已向服务器保存。
- 旧统计写入口缺 CAS，自动更新缺可信签名与可靠发布契约；不为追求表面完整增加猜测写入或执行。
