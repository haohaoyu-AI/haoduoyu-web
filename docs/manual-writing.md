# 本次手动双作者工作页

从写文页点击“本次手动双作者写文”，进入 `/writing/manual-run`。所有操作要求本人登录；页面加载和“只刷新状态”只读取数据。

1. 分别填写小鱼、Claude 的选题、核验材料和 2–12 条 HTTPS 来源。检查当前模型及完整 V2 版本，勾选确认后点击“创建并冻结本次唯一批次”。创建不会调用模型。
2. 分别点击两位作者的认领按钮。认领口令仅留在当前页面内存，以密码框展示；不写入 URL、localStorage 或 sessionStorage。不要在尚未完成保存时关闭或刷新页面。
3. 小鱼原稿使用 `title` 和 `paragraphs` 两个字段的 JSON，标题与正文分开；正文 2000–3000 字。点击“原样保存小鱼文章”。来源由服务器使用冻结快照，不接受新来源或改题。
4. 勾选 Claude 的独立执行确认，再点击“执行 Claude 一次写作”。本批次仅允许已配置 YYLX 模型的一次请求，14000 输出上限、300 秒、不重试。完整输出只保存网站文字稿，保存成功即完成；配图排版与平台流程只用于人工上传文章。
5. 断线时先点击“只刷新状态”。已有模型请求不会再次执行。若模型已完成但文章未存，使用“仅保存已完成原稿”；有效期已过时，先续认领同一篇已完成原稿，再仅保存缓存。

## 页面使用的正式路由

- `GET /api/writing/manual`：读取本人批次、模型名、提示词版本和真实 Claude 结果；不返回认领口令
- `POST /api/writing/manual`：同源、本人鉴权及 `x-xiaoyu-manual-writing: 1`；请求为 `{action,input}`，动作仅为 `create`、`claim`、`save_xiaoyu`、`save_claude`、`renew_claude`，对应页面显式按钮，复用同一套服务端写作函数
- `POST /api/claude/manual-run`：同源、本人鉴权及 `x-xiaoyu-manual-run: 1`；页面提交当前批次、文章、认领口令、冻结模型和 `confirm: true`，通过 NDJSON 返回进度与终态

这些路由不接受客户端新增授权槽或自选批次编号，不能扩大一次请求上限，也不会改动每日、测试或旧稿记录。错误只返回安全枚举，不回显请求正文、口令或数据库异常。
