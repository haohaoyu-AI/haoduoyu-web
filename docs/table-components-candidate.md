| 组件 | 指定调用点 | 输出/求值边界 |
| --- | --- | --- |
| 表格框架 | articleTable、renderPeriodAccounts、renderAttentionArticles、renderPlatformTable、renderTopTable、renderDailyTable | 复用 table-scroll/table/thead/tbody 标签；表头、行内容用延迟渲染回调，维持原先表头先于行体的求值顺序。class/属性来自原调用点静态字面量，保留空白、属性顺序与文章 tbody class。 |
| 指标单元格 | 上述函数中原本完全相同的 td[data-label] 形状 | label 在原位置求值并经过原 e()，单元格内容延迟到 label 转义之后计算；不改变数值/null/0/缺失/coverage/comparison/排序含义。非匹配单元格保留原文。 |

## 有界净收益门槛

当前未压缩 UTF-8 ESM 为 115637 B，整体目标仍为 100000 B，缺口 15637 B。先完成这一组自然组件并用原 esbuild 参数实际构建，扣除组件、调用、回调及导入成本。

- 首个完整候选必须净减至少 3000 B（产物不超过 112637 B），才值得进入扩大范围/完整合并验收；这是本轮停止门槛，不是放宽整包目标。
- 收益不足即冻结候选、保存具体实现与构建结果并报告；不连续添加无边界改造凑数，不宣称整体达标。
- 静态毛重复、模块原体积或以前的2804 B/113 B试验均不计为本候选收益。

## 等价证明与守卫

先保留现有全部守卫。只有收益门槛通过，才实施精确的等价证明替代，禁止先删除冻结断言来取得绿灯。

1. 对指定组件函数和调用点建立显式 AST 清单。只展开获准的 helper 调用；确认 helper AST 只含指定模板/回调调用及 e()，不读写状态、不增加 fetch、事件或业务分支。参数求值及回调执行按原顺序展开，再与基线整个函数 AST/全部 cooked 字符串比较。未指定声明、表达式及文件必须保持冻结，不以忽略某文件代替证明。
2. 变异负例必须拒绝：改变用户文字/空白、data-action/ARIA、去掉或重复 e()、改变 getter/回调顺序、插入副作用、修改非指定调用点、手改生成产物。只比较候选自身稳定 hash 不算等价证明。
3. 渲染差分比较完整 HTML 字符串与 coercion/getter 轨迹，涵盖0/null/未取得、空表、可选列、赞同、未核实日期、分组、特殊字符及不合法链接等既有边界。精确记录哪些实际已执行。
4. backend-utilities 的5a历史前端未变证据仍保留；当前 runtime/.openai/db/drizzle 和非授权 public/web 路径继续冻结。仅 public/app.js 可由已证明的源码变换生成且须在重建前一致；现有旧后端完整 HTTP/body/status/header 差分必须继续实际运行，不用静态替代或只测候选。
5. 收益及结构门槛通过后，再进行受影响页四宽（375/390/768/1440）真实合成 Cookie/CSRF 浏览器验证及菜单/焦点/键盘回归，保留原始像素差异和可见 UI 判断。未执行阶段不写通过；不重复无关大型基准。
