## 实施边界

- 严格核对 complete、唯一记录、账户归属、总数、状态与日期分组，以及公众号显式 gzh 槽位的编号聚合。编号只展示重复与已记录编号之间的内部间隔；起点、目标、样本映射未知，排期未配置，不推断应产出、缺产或逾期。
- 对账保留服务端已读快照，本机排队、Unknown、冲突和草稿不混入服务端完整计数。待核 true/false/null 分开，空警告与未知状态不互相替代；筛选在完整快照上先过滤后分页，分别标注全范围与筛选计数。
- 刷新需当前连接、完整账号列表、对账与身份校验全部成功后一次提交缓存；失败、取消、坏响应或归属变化保留原缓存。快照保存该次已核实账户集合、服务 scope 和本机观察时间，观察时间不是服务器事务版本。
- 完整离线准备同步纳入对账库存，补齐五个已知状态之外的详情，与已知分页交叉核对后才标完整；批次前后读回对账用于检测变化，不能消除无服务器修订号的 ABA/并发窗口。
- 只读摘要不能作为写入实体；打开完整文章必须另取完整详情与真实版本。目录和链接只显示，不执行、不发布平台内容。
