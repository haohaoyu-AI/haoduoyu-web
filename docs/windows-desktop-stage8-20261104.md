## 双来源与完整性

- 服务端模式直接读取并缓存经身份/响应校验的原始页，保留原 meta 的 total、unfiltered_total、page 和 has_more。本机未决修改单独提示，不用零散缓存数量覆写服务器总数。unfiltered_total 的源定义是当前授权范围加所选状态，账号查询条件不会改变它。
- 本机模式才使用离线投影：当前草稿/已排队修改按原有语义保留，筛选在本机已知集合上先应用、再排序分页。只有 exact `/articles` 的带完整标记、同分区、计数一致库存可称完整已准备基线；无参数网络 GET 默认只读已发布，不据此冒称全部库存。
- 局部页、摘要或字段缺失保留“当前已知/未完整”的提示，不能报告本机已知数量为服务器总量。索引字段模式不能授权文章编辑；条目仍须单独完整详情、真实版本和原草稿 key，Unknown 围栏不变。
- 对投影后的当前记录重算警告、待核三态、题材、日期/快照状态、缺失指标及生产耗时；改账号时按新账号重新关联平台/名称，避免复用旧派生信息。派生字段只读，不写回文章。
- 切账号清空筛选、分页、来源和结果；查询或读取失败保留原缓存、草稿和队列，不产生业务写入。
