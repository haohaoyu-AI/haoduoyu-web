# 明确公开状态与24小时观察合同

网站文章 URL 可读、登录态个人主页出现、私人草稿保存或定时预览均不证明公开发布。指标采集工具只接受精确字符串文章 ID，且必须与独立历史中的对应本人草稿 ID 一致。`publication.status` 和 `status_source` 保存实际作品管理/明确平台状态及原文 `status_text`；只看到页面时应记 `unknown`，不得记 `published`。定时发布中的原有日程只读保留，不修改。

发布时间单独保存：每个 `time_sources` 保留来源、原文、实际核验的时区及规范化时间。未知时区留 null。只有明确已发布、全部时间来源与核验的 `published_at` 一致时，`time_status=verified` 才允许计算24小时。两个来源相差15小时且时区未核实应记 `time_conflict`，`published_at`、24小时区间和到期时间全部为 null，不能选一个时间硬算。已发布的当时累计指标可独立保存并显示真实采集时间；仍不称24小时快照。
