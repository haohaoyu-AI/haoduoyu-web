# 日记小标题

在碎碎念当日工具栏，只手动填写。标题按页面选中的北京时间日期存储，与打分互不依赖；清空并保存表示没有手填标题。访客只看到登录入口，登录后仅已配置的所有者可以查看、填写。

- `GET /api/v1/diary-titles/YYYY-MM-DD` 返回 `date,title,version,updated_at`（标题未填时为空字符串）。仅限网站所有者会话，或已连接且代表同一所有者的 MCP 只读调用；不公开匿名读。
- `PUT /api/v1/diary-titles/YYYY-MM-DD` 仅网站手动保存：`{title,version,save_id}`。需真实所有者会话和现有同源/CSRF 保护，MCP 写入拒绝。并发修改返回 409，保留本机输入让用户核对。
- 发布前通过正式备份流程核验备份，再通过授权 D1 管理界面应用仅新增表的 `0030_diary_titles`。旧 Worker 可继续使用原有表；回滚时不要删除新表。发布不改已有标题、分数、日记或定时。
- 待归档服务的只读身份另行核实；不要把此页面功能或日记小标题接口等同于 05:00 定时已接入。禁止把日记正文或标题汇报给公开访客。
