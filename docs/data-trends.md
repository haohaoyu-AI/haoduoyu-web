## 统计口径

- 按文章 `published_at` 归日。未来日期或具体时刻、无效/缺失日期、明确草稿/排期/失败等未发布状态不计入趋势，并分别显示排除数。
- 平均阅读是有效阅读样本的算术平均，不是总览中位数。各指标有自己的有效样本分母；真实零保留，缺失留空，图形断线。
- 每篇选择已记录 `age_hours` 在 12–72 小时、最接近 24 小时的同一份快照。没有合格快照时不取长尾或另一份指标补缺。
- 排除未来快照、早于发布时间的快照，以及与已知发布时间矛盾的未来观察年龄，容许整数年龄四舍五入 1 小时。
- 爆款沿用完整账号最近 30 篇有效样本的既有分位数规则，与文章列表共用基线。不足 10 篇时以阅读 ≥1000 暂定。未来、无日期、未发布记录不计入趋势，但不单独重算阈值。
- 趋势排除异常快照时可能采用不同的有效样本；共享的是判定阈值，不能承诺异常输入时逐篇判定必然相同。
- 发布未满 24 小时或选中快照年龄小于 24 小时的记录单列暂定。近日仅日期且无年龄的记录标成熟度待核实。未判定与暂定判定分开；没有判定样本时爆款数、爆款率留空。
- 展示快照日期范围、样本年龄范围及实际读取时间。源快照只有日期，不伪造精确采集时刻。明确“今天未完”和“累计阅读不是每日新增阅读”。

## 发布状态

当前 `matrix_review_articles` 独立于旧生产流水线；API 允许只提供标题，`published_at`、`url`、`platform_article_id` 均可空，没有逐条 `status` 和平台发布核验。
早期文档 “Only successfully published articles are recorded” 不能替代这项资源的状态证据。
因此有日期的记录显示为“发布时间记录数”。有待核实记录时“已发布篇数”为 `—`，同时列确认数/待核实数；全部明确已发布时显示篇数；空集合显示 0 并说明不是平台完整发布总数。
计算层支持已有明确 `status`、`publish_status`、`publication_status`，不新增字段、不猜测外链、不按标题跨库拼接状态。

## 实现与可复现验收

- 计算：`web/core/review-trends.mjs`；渲染：`web/pages/review-trends.mjs`；共享账号基线：`shared/review-analytics.mjs`。
- 日期范围、指标及筛选保存在路由，刷新和切换后保留。读取失败沿用现有错误页，不用旧数据冒充刷新成功。
- 单个 SVG 使用百分比横坐标和固定 CSS 像素的文字、点及纵轴；手机筛选为两列。折线保留缺失断点，逐日表在自身容器内横向滚动。
- 执行 `npm ci --ignore-scripts --no-audit --no-fund`、`npm run build`、`node scripts/frontend-build.mjs --check` 和 `npm run check:artifacts`，核对生成包及 18 项资源。
- 复盘定向测试：`node --test --test-concurrency=1 tests/review-*.test.mjs tests/content-review-*.test.mjs`；诊断回归为 `tests/openai-*.test.mjs`。
- `node scripts/verify-data-trends.mjs` 离线生成完整合成输入/预期/实际，覆盖空值、真实零、未来、无日期、北京时间跨日及显式草稿。
- 浏览器夹具：构建后运行 `node tests/review-trends-browser-server.mjs`，必须等 `SYNTHETIC_TRENDS_READY` 再打开页面。仅使用临时本地 D1，禁止外联，不读取生产数据。
- `TRENDS_BROWSER_WIDTH=390 python3 tests/browser-review-trends.py` 可单独验收某个宽度。每个宽度重新启动夹具，隔离种子数据和限流状态，不修改生产限流保护。未指定宽度时测试 1440/390/375。
- 浏览器检查 7/30 天、自选边界、指标、刷新、页签/键盘、错误恢复、判定筛选、前进/返回、无横向溢出、无写请求，并测量实际文字/点尺寸和选项宽度。失败保存截图及错误报告。
- 故障模拟显式阻断 Service Worker，保证网络拦截确实发生；这不替代独立的 Service Worker 恢复/草稿保护回归。
- 当前本地 Chromium 因 Unix socket 限制不能运行。隔离 GitHub 验收使用官方浏览器、固定源码对象和精确树/Worker 摘要；不回写代码、不使用生产凭据，结果与截图链接在 PR。

定向通过不等于全仓绿灯。全仓 `check:web` 基线 125 项、本次 124 项，趋势新模块没有违规；历史完整测试存在旧迁移/UI 契约失败及未结束 Promise，最新执行结果应逐项查证，不把全部失败推给基线。
