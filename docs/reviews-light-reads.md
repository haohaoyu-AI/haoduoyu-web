新增 due-reviews 只读取授权文章及 kind/as_of 观察节点，不调用 overview、不读每日数据、不计算累计指标。buildOverview 与 due 接口共享纯函数；C5 精确失效也复用同一未完成节点事件表，避免谓词分叉。只认已核实日期、同 kind 且 as_of>=due 的完成记录，排序和输出保持。

fields=index 只返回 id/title/account_id/platform/published_at，不查询快照，保留授权、文章自身字段过滤和原分页规则。约束冲突的明确取舍：指标/最新快照排序以及依赖快照的数据状态无法在完全不查快照时正确执行，新索引模式对此返回明确 400；date_unverified、题材和其他文章自身字段支持。旧的未带 fields 接口保持全部行为与字段。此限制在 OpenAPI 新参数中明确，待独立验收；不静默伪造过滤结果。

前端索引以会话身份和规范化完整查询为键，最多保留十组 promise/不可变最小记录。真实成功写请求在统一 api 路径、解析 JSON 前清理 generation；登录初始化、登录页/401、退出和手动刷新也清理。旧在途请求不能重新填充已清理 map；同会话写后重新取新 generation，换身份响应拒绝。渲染和弹窗在使用前再次校验 generation 与原 render/modal 版本。失败项删除，后续可重试。

索引使用单独 reviewArticles，不覆盖文章页含 url 等字段的完整 state.articles，避免打开录入弹窗后原文菜单丢失。模板和 e()/safeURL 未改。
