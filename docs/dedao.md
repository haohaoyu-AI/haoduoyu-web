# 得到大脑：本机连接、验收与恢复

网站入口：https://haoduoyu.xyz/dedao 。请在当前已登录得到的电脑上连接；程序会自动识别电脑名。

## 第一次连接

1. 在当前已登录得到的电脑上下载网站页面的“本机执行程序”，解压整个文件夹。不要直接在压缩包内运行。
2. 双击 `Verify-1-Then-3.cmd`。它会连接本机，并从网站的真实“求助成文”按钮先启动 1 篇，提交成功后再连续启动 3 篇。
3. 如果程序提示浏览器授权，在已经登录得到的 Edge 打开 `edge://inspect/#remote-debugging`（Chrome 使用 `chrome://inspect/#remote-debugging`），允许远程调试；稍后出现连接弹窗时点击允许。需要支持此功能的新版 Edge/Chrome。不要向公网开放端口，不需要复制 Cookie 或关闭原浏览器。
4. 如果弹出网站授权页，用网站本人的账号登录并同意授权。如果提示 Codex 尚未登录，按 Codex 的登录提示操作。无需填写 API key，也无需复制令牌。
5. 保留执行窗口和这台电脑的浏览器，避免电脑休眠。网页可以刷新或关闭，实际执行会继续。

程序自动复用已有 Codex 原生执行文件和登录，找不到时在当前用户目录安装官方 CLI；自动发现已允许连接的浏览器，建立下载目录、注册执行端并回传进度。没有合适 Node.js 时，Windows 入口会下载官方 LTS 并核对官方 SHA256；不需要管理员，不改全局 PATH。依赖使用随包锁文件安装。

网站本人授权与 Codex 登录是两次不同的授权。首次本机启动、浏览器的“允许”和本人账号的登录同意需要你操作；云端会话没有这台电脑的终端连接，不能替你完成这些动作。缺少权限或连接时程序会提示，网页继续显示“执行端未连接”。程序不会把未连接显示成验收通过。

换电脑时，在新电脑重新解压启动执行包并确认本人授权。不要复制旧电脑的加密授权文件。若旧电脑有未结束的批次，先确认原执行已经停止；在网站恢复同一批次，不能另建重复任务。已下载的 Word 若只保存在旧电脑，需要保留原文件与来源记录，不能在新电脑冒充一次新的下载。

## 以后怎样启动、暂停、恢复

日常启动：双击 `Start-Dedao.cmd`，等网站显示已连接。在网页填写生成篇数，再点“求助成文”。一篇提交给小鱼后才会开始下一篇。

暂停：在网站点击“暂停当前批次”。网页先显示等待执行端停止，原 Codex 进程确认退出后才允许恢复。暂停不会撤回已发出的得到消息或已提交给小鱼的文章，也不会终止小鱼后续配图。

恢复：先解决页面说明的问题，例如在原 Edge/Chrome 重新登录得到。确认执行窗口仍在运行；如果窗口关闭，重新双击原来的入口。等网页允许恢复后，点“恢复当前批次”。程序先核对原对话、文件和服务器记录，从已确认的步骤继续，已经提交的文章不会再生成或求助。

验收窗口中途暂停后，只需在网站恢复当前批次；同一个窗口会继续核验，并自动推进后面的 3 篇。验收入口完成过一次后再次打开会显示原结果，不会再生成四篇。

停止整台电脑的连接：在执行窗口按 Ctrl+C。网站任务会保留，原执行退出回执确认后可恢复。直接关机或断网可能使页面暂时无法确认原执行是否仍在继续；程序重开后先检查原 PID 和服务器结束回执，不能只凭心跳过期另开任务。

## 文件和真实验收结果

默认目录是 `%USERPROFILE%\.haoduoyu-dedao`：

- `downloads\批次编号\篇次\实际文件名.docx`：从得到下载的原 Word。
- `execution.json`：真实 Codex 线程、PID、排队版本，以及实际退出/服务器确认记录。
- `receipts`：下载回执，保留原浏览器来源、标题、最新版本和文件 SHA256。
- `acceptance-1-3.json`：这次 1 篇再 3 篇的启动键、实际按钮回执、四篇标题、文件、上传 ID、小鱼提交 ID 和时间。只有四篇都得到真实证据才会写入 `completed: true`。
- `config.json`：非秘密本机配置。
- `oauth-vault.json`：网站授权。Windows 使用当前账户 DPAPI 加密，其他系统限制为当前用户可读。不要发送这个文件给别人。

每篇完成的含义是“已提交，等待小鱼接手。无需再次点击。”，不等配图或平台发布。最后一篇已提交时，网页还可能短暂显示“等待执行端确认结束”；这与稿件提交成功是两个事实。

服务器保存独立的批次、篇次、发送意图、实际回应、最新定稿版本、Word 文件、固定上传对象和小鱼通知。未知发送先检查原对话；未知下载先核对已有文件；未知上传和求助先查原服务器记录。不能证明的动作会暂停，不盲目重做。浏览器重启后已下载的 Word 仍须核对原来源和实际字节，不能换成新的下载身份。

如果得到导出的 Word 不符合网站现有格式要求，程序保留得到最终稿并暂停。Codex 不得为了通过上传解析器自行改稿。

## 已有配置与特殊环境

执行包复用网站已有 Sites OAuth/MCP 和 `article.submitted` 小鱼订阅，不开放公网入站端口。网站 OAuth 授权资源保持原 MCP 域名：`https://xiaoyu-event-test.haohaoyu202409.chatgpt.site/mcp`；直接改成 haoduoyu.xyz 可能使原授权失效。

已有环境变量优先于自动配置：`DEDAO_MCP_URL`、`DEDAO_CDP_URL`、`DEDAO_CHROME_PROFILE`、`DEDAO_DOWNLOAD_DIR`、`DEDAO_CODEX_BIN`、`DEDAO_CODEX_PROFILE`、`DEDAO_EXECUTOR_ID`、`DEDAO_WORK_DIR`。Windows 的 Codex 路径须为原生 `.exe`，不使用 `.cmd/.bat` 包装。已有安全注入的 `DEDAO_MCP_ACCESS_TOKEN` 仍兼容，常规入口使用自动 OAuth 和刷新，不要求手工复制令牌。

如果浏览器版本不支持当前已登录会话的调试授权，需要升级浏览器或提供已可用的本机 CDP 地址；不要绕过浏览器保护或搬运 Cookie。如果网站 OAuth 服务器不支持本机客户端注册，程序会明确停止，需要检查现有 Sites 客户端授权配置；不会用模拟登录替代。

离线合成测试证明输入校验、持久记录、锁、串行编排和文件验证机制，不能替代这台电脑的真实 1＋3 篇验收。网站上的完成状态只来自实际任务和小鱼提交记录。
