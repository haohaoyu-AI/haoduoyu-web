## 本轮改动

0.15.0增加独立的原生跨日提示。此前日期在启动时固定，跨过北京时间午夜或休眠数日后仍可能停留在原日而没有提示。现在每30秒由DispatcherTimer观察日期，窗口重新激活也立即观察；只在自然日变化时显示提示，不在每次轮询时重开已关闭的同日提示。多日跳跃只提示实际新日期，时钟向前或向后调整均重新观察，不逐日补执行任务。

观察日期本身不保存设置、不改所选日期、当前模块、正文、缓存或队列，不发出HTTP或同步。用户可继续原日期。只有明确点击“打开今天待办”才先完整flush原编辑稿，随后打开当前北京时间日期的待办；落盘失败时保留原页、原日期、未完成输入和提示。旧日期草稿及已排队请求的日期、ID、版本、字节均不迁移到今天，也不重排Unknown。跨页读取期间若再次跨日，保留更新后的提示。窗口实际关闭后停止日期计时器。

窗口时钟可在合成测试中注入，生产仍使用TimeProvider.System；原生日期按钮、未安排事项“今天完成”和AI汇报日期校验均使用同一窗口时钟。状态与文件schema不变，不引入联网定时任务、系统通知权限或安装服务。
