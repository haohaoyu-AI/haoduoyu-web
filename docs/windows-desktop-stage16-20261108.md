## 实际改进

此前所有原生文字导出在SaveFileDialog确认后直接File.WriteAllText覆盖旧目标，写入出错可能留下半份文件。0.16.0统一改为严格UTF-8无BOM、64MiB实际字节上限，同目录CreateNew随机临时文件，完整写入并flush到磁盘后才File.Replace已有文件或File.Move首次新文件。没有delete-then-move及非原子覆盖回退。取消发生在提交后时不会谎报“未导出”。

准备前及提交前检查目标：最终符号链接/重解析点、目录、只读或不可写目标明确失败；发现普通长度/修改时间/创建时间变化时停止。原本不存在的目标只使用不覆盖Move，竞争创建不会获得隐式覆盖权。无法用跨平台托管文件API提供inode级条件替换，恶意目录竞态/ABA及目录链变化仍非本功能可证明消除的范围。真实断电、介质故障及文件系统自身的持久化保证仍待实机验证。

失败或提交前取消会清理本次临时文件，不删除原目标。若清理也失败，异常明确报告临时纯文本可能残留并保留两次错误原因，不能显示导出成功。产品入口把文件操作安排在线程池，UI只在完整提交后显示成功；不会联网、改缓存、排队或清除编辑器dirty状态。导出故意不先flush工作区，避免本机草稿存储受阻时连抢救文字都不可用。
