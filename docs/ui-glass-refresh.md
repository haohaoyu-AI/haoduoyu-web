色彩：正文 `#24323f`，次级文字 `#62646b`，主操作 `#a44e38`，悬停 `#853e2b`。背景使用静态 CSS 杏色 / 珊瑚 / 青灰渐变，不下载字体、背景图或第三方资源。正文字体保持系统中文字体。

桌面外框 28px 圆角与 28px 外边距，普通卡片 20px 圆角；薄白框和 57% 白色表面承接背景，弹窗使用 94% 近白表面保证可读性。正文不会整体降低透明度。按钮和输入最低 44px。

桌面沿用侧栏与宽内容区；761–1100px 使用 88px 图标侧栏；760px 及以下采用单列卡片、折叠侧栏与悬浮底部导航。待办仍直接显示输入框、圆形勾选、菜单和完成隐藏模式。

## 实现与集成

- `public/glass.css` 为独立视觉层，在基础样式及各模块样式之后加载。
- `public/index.html` 引入该文件并更新浏览器主题色；构建资产清单与 `.ci/public-assets.json` 同步登记。
- `public/app.js`、现有 `public/style.css`、业务控制器、API、数据库及权限均保持原有内容。
- 模糊仅作用于桌面外框与手机底部导航；手机外框关闭模糊以保持固定导航定位。提供不支持 backdrop-filter 的实色降级、reduced-motion 和 forced-colors 规则。
- 备忘录未合并。只读取得整合分支 `6043d18cd75634542baecc6ffa665712cdf32eb1`，在仓库外隔离副本加载视觉层并验证。后续整合应保持顺序 `style.css` → `memos.css` → `glass.css`，合并两边的构建资产条目并重新计算 HTML 哈希；不得用旧构建包覆盖新基线。

## 验证与截图

所有浏览器数据均来自 loopback + 临时 D1 合成夹具，无生产请求或写入。

- 62 项定向 Node 测试通过：shell、弹窗、文章索引、todo、碎碎念及严格样式策略。
- 核心总览 / 文章 / todo / 碎碎念：1440×1000、375×844、390×844 共 12 张截图；另有各宽度文章详情和筛选共 6 张。均无文档横向溢出、JS 页面异常、未命名可见按钮或外部请求。详情关闭后的焦点返回、筛选 Escape 关闭通过。
- 1024 / 760 的布局及 reduced-motion 检查通过，含平板侧栏边界、手机侧栏开关与 inert 状态。
- 碎碎念真实 Worker 联测通过：所有者登录、自动保存、独立匿名阅读及只读边界、软删除。
- 备忘录隔离集成的 10 项真实 Worker 检查通过，覆盖桌面、375px、公开只读、编辑、冲突、未知提交结果、离线恢复和回收站。它不是本分支已合并功能。
- 既有 todo 浏览器脚本补充显式选择“已发布”：该夹具种的是已发布文章，而当前文章页面默认已存草稿；未改产品默认值。

待办浏览器验收的 13 项检查全部通过，含触控长按、菜单键盘导航、失败回滚、隐藏模式、软删除与撤销、跨模块迟到响应以及历史记录隔离；最终产物哈希检查通过。最终远程 CI 状态见交付说明。
