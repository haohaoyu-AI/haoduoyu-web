## 可复现问题与修复

1. **重复登记被误报为并发编辑。** 原界面把所有 `409` 都显示成“这条记录已被其他人或 AI 更新”。实际浏览器重复提交同一文章链接，后端返回 `ARTICLE_EXISTS` 和“该平台文章或链接已经登记”，页面却给出错误处理建议。现仅 `VERSION_CONFLICT` 使用并发提示，其他错误显示后端具体原因。回归同时验证重复提交与两个真实浏览器页面的版本冲突，避免修复掩盖正常并发保护。
2. **手机登录页超宽。** 移动端单列网格的自动最小宽度被登录表单撑到 `400px`；390px/320px 会缩放或横向溢出。改为 `minmax(0,1fr)`，保留既有桌面布局。测试比较文档宽度与配置的物理视口宽度，避免被移动浏览器扩大 `innerWidth` 掩盖问题。
3. **320px 驾驶舱的长标题挤出补录按钮。** 长且连续的标题令等待复盘条目的 flex 子项无法收缩，按钮右边界超过屏幕，文档宽度达到 `327px`。为文本列设置可收缩宽度，并允许长内容折行；补录按钮保留在卡片内。测试用包含长字符串和 HTML/XSS 片段的合成标题复现，修复后 320px 无整页溢出。

没有改变数据库 schema、指标聚合、快照追加、审计规则或 API 权限。

## 实际执行与结果

```bash
cd matrix-web
npm run check
npm run test:browser -- --artifacts /tmp/matrix-browser-qa/final
```

`npm run check` 通过。浏览器回归包含桌面与手机两个完整测试用例，两项均通过，无失败或跳过。修复前回归实际失败于重复提示和手机登录超宽；修复后继续检出 320px 长标题溢出，最终全部通过。

## 尚未验证

本轮是本地 HTTP、headless Chromium 与手机触摸模拟；没有验收真实手机、Safari/Firefox、生产 HTTPS 代理链、真实安全 cookie 存储行为、外部 Grok 或平台采数。没有重新运行 AI 凭证管理、密码重置、CSV 下载等不在本轮范围的页面流程，前轮证据仍按原日期保留。

上线仍需确定长期托管目标、独立域名和 HTTPS、实际代理信任地址、持久卷与备份运维，并由用户在目标主机设置真实管理员；这些缺项与本轮前端修复无关。
