# V1 验收计划

本轮已在开发环境执行自动化与浏览器检查。下表区分已取得的验证证据与仍需目标环境验收的事项；详细场景清单用于持续验收，不能把整张清单理解为全部生产验收通过。测试使用独立数据库与合成业务数据，不使用真实平台凭据。

| 本轮已验证 | 仍待生产或真实执行器验收 |
| --- | --- |
| 20 项自动化测试通过；覆盖认证、账号范围授权、只读与撤销、CSRF、幂等重试、版本冲突、日期与指标校验、北京时间三日汇总。 | 实际 Docker 镜像构建、生产主机与持久卷权限。 |
| Node 内置 SQLite 在线备份可读回、备份文件权限 `0600`、数据库重开后文章及账号设置保留。 | 生产备份导出、隔离新卷恢复、切换与回退演练。 |

## 运行与持久化

- Node.js 24 可启动服务，`GET /health` 成功且不含业务或凭据；无需模型服务或 OAuth。
- `/openapi.json` 为可解析的 OpenAPI 3.1，`/api-docs` 匿名可读；接口路径与实际实现一致。
- 初始账号仅为配置；没有虚构文章、阅读或互动数据。空首页显示缺失状态。
- 重启应用、删除并重建挂载同一卷的容器后，账号、文章、快照、日报和 key 撤销状态保留。
- 生产 `SITE_ORIGIN` 为真实 HTTPS 来源；生产错误配置不能悄悄降级为不安全来源。

## 管理员认证

- 只有 CLI 能首次创建管理员，没有公开注册或默认密码。密码从 stdin 接收，不出现在参数和日志。
- 错误登录返回通用认证错误；重复失败被限流，避免通过错误差异枚举用户名。
- 登录会话使用生产安全 cookie；退出后旧会话失效。
- 浏览器会话写入必须同时具备正确 `Origin` 和有效 `X-CSRF-Token`；缺失、错误及外部来源被拒绝。
- 修改密码需校验当前密码；CLI 重置使用同一实际数据库，旧密码和该用户所有旧会话失效，需重新登录。
- 数据库只存密码 hash、会话 hash 和 API token hash，不存原始密码或 token。

## API key 与边界

- 管理员创建限定账号的 key，原始 token 只返回一次，列表和审计不再返回 token/hash/密码。
- 匿名读取业务接口、无效 token、已撤销 token 被拒绝。
- `read` key 可读获授权账号，不能写；无 `read` 的 key 不能读取业务数据。
- key A 不能读写账号 B 的文章、快照、日报、列表、驾驶舱；伪造 `account_id`、`article_id` 或将文章转到 B 同样失败。
- API key 不能管理用户、密码、账号配置、其他 key 或审计；只读 admin 功能按实现严格隔离。
- 撤销 key 后同一 token 立即失效；日志不得回显 Authorization。

## 发布记录与并发

- 中文账号名称、文章标题、摘要、备注、URL 均可保存并回读，页面和 CSV 显示正常。
- 同名不同平台账号可区分，切换账号同时过滤发布表、复盘、驾驶舱和详情。
- 停用账号仍可读写历史修正与复盘；新建文章或将其他账号文章迁入时返回 `409 ACCOUNT_INACTIVE`。
- 时间需要带时区；开始时间未知时耗时缺失，不能显示 0 或负耗时。实际开始晚于发布时间被拒绝。
- 人工、自动化、混合、未知方式分别保存，未知不会自动归为人工。
- 相同规范链接，或同平台相同文章 ID，重复登记返回冲突；该去重范围跨本站运营账号，测试应覆盖此边界。
- 两个执行器从同一 `version` 修改文章：首个成功，第二个返回 `409 VERSION_CONFLICT`，不能覆盖前者。
- 同一幂等 key 与同一请求重放返回同一结果，不重复新增文章或快照；同一 key 不同请求返回冲突。
- 模拟写入成功但客户端未收到响应，用原请求重试并回读可确认真实保存结果。
- 页面中的脚本、HTML 和 CSV 公式前缀按非可信输入处理，不执行作者输入。
- 无文章删除 API；历史累计快照为追加记录。

## 指标、缺失与复盘

- 仅允许 `reads`、`impressions`、`likes`、`comments`、`favorites`、`shares`、`approvals`、`reading_users`；负数、小数、超出安全整数、未知字段及空指标对象被拒绝。
- 阅读人数和阅读次数、赞同和喜欢分别显示与保存，不生成跨平台统一触达或互动率。
- 未采集或不适用指标保持缺失；真实零值可保存为 0；缺失不填 0。
- 累计快照保存 `as_of` 与实际 `collected_at`；最新快照按 `as_of` 判断，晚录入的旧快照不能覆盖当前最新数据。
- 快照累计值不被相加为区间量，也不自动推导自然日日增量。
- D1/D3/D7 目标到期会提醒；迟采记录保留实际时间，不冒充准点采集；漏采不补造历史值。
- 后续累计值因平台更正而下降时，仍保留实际观测历史与来源备注。

## 三日驾驶舱与日报覆盖

- 北京时间日期边界前后验证窗口始终为今天及前两天；不是最近 72 小时，`todayIncomplete` 明确标识今天尚未结束。
- 只有累计快照、没有日报时，三日阅读显示缺失，不把最新累计值充当三日阅读。
- 同账号、同日存在账号整体日报和文章日报时，账号整体优先，不将二者相加。
- 没有账号整体日报时，文章回退汇总标明覆盖范围与缺失日期，不能声称覆盖全部文章。
- 同一账号、文章范围、日期的日报重复提交更新同一条，metrics 整体替换、不累加、不隐式合并；缺省 `article_id` 的账号日报同样只能有一条。
- 总体日报的 NULL 文章范围与文章明细范围相互区分，不能被 SQLite NULL 唯一性行为绕过去重。
- 不同指标在不同日期缺失时，各指标使用实际有数据日期，并显示 coverage；整日缺失与真实零值可区分。
- 文章发布时间不在三日窗口，但在窗口内产生真实日报时，其当期发生量按正确口径计入。
- 顶部文章数、自动化篇数、未知方式数和耗时统计，与筛选账号及定义一致；空集与未知耗时不会产生误导性 0。累计表现按最新累计阅读排序，不能标作三日新增榜。

## 部署与恢复

- 真实 HTTPS 反向代理下登录和 CSRF 正常，应用容器端口仅向必要内部网络开放。
- SQLite 专用数据卷可写，重建后数据保留，不使用临时层作为生产数据目录。
- 使用项目在线一致性备份，或停服务后完整归档数据卷；恢复时停止写入，在隔离新卷验证完整性与业务记录，保留旧卷和旧镜像用于回退。
- 恢复后核对备份时期的会话及 key 撤销状态，避免重新启用后来已撤销的凭据。
- 若接入外部 AI，用独立受限 key 完成一次“查账号—写记录—回读—同 key 重试—越权拒绝—撤销后拒绝”闭环。该项须执行后才可报告接入成功。
