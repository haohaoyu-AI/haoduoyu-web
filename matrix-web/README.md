# 好多鱼图文 · 账号矩阵

独立的个人自媒体统计网站，支持账号密码登录、授权 AI 回填、已发布文章表格、复盘快照与账号驾驶舱。旧项目和旧数据库保持独立。本目录可以单独部署，无 OpenAI 登录和生产依赖包。

需要 Node.js 24 或更高版本。数据库使用 Node 内置 SQLite，部署时保留数据卷。

## 本地运行

1. 在本目录执行 npm run admin -- create --username admin，在交互提示中设置自己的密码（至少 12 字符）。
2. 执行 npm start，打开 http://localhost:3000。
3. 登录后在「AI 接入」创建限定账号范围的凭证，将其配置给 Grok Bot。

只有三个运营账号的配置会自动初始化，没有演示文章或虚构指标。新账号通过页面添加。

## 功能

- 全局账号切换：头条·好多鱼、知乎·好多鱼、公众号·小鱼儿真保鲜，支持继续添加。
- 发布统计：只登记已成功发布文章，生产方式与录入身份分别记录，耗时由选题开始至发布时间计算。
- 复盘：累计最新／1／3／7 天快照追加保存，实际采集时间保留；按日发生量单独回填。
- 驾驶舱：北京时间今天及前两天发生的数据，包括旧文章的新效果；缺失与真实零值分开，账号总量和文章明细不重复相加。
- Grok API：可撤销凭证、读写与账号范围限制、幂等提交、文章版本冲突检测、审计。
- 管理：改密码、账号停用、文章 CSV 导出、数据库一致性备份。
