## 先发布 V159 页面补丁的评估

1. V159 `/api/articles` 没有当前 Home 要求的 `owner_scope`；普通上传稿还可能在
   `recent` 最近五条中，当前选择逻辑会排除这些稿。直接搬当前 Home 会拒读或隐藏稿件。
2. V159 没有 `/api/articles/workspace`、`/api/article-data`、`/api/dedao/cloud`，
   不支持当前收起/恢复、文章数据和云端一键页。

`lib/result-observation-time.ts`；导航只能摘除写作台入口，不能带入不存在的文章数据链接。
该结论仅是源码/DTO评估，不是已建成、测试通过或部署的 V159 组合版本。

状态的保证。我们没有删减当前迁移集合、改绑定、改 journal、猜配置或擅自假定回滚契约。
