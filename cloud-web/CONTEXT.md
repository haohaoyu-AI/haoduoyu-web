# 产品术语

- **文章任务**：围绕同一篇原文处理配图和 Word 成品的任务。
- **配图准备**：读取原文并搜集、整理公开图片候选。
- **Word 处理**：取得并检查实际图片字节，确定配图，生成 Word、逐页检查并保存成品。
- **等待处理位**：任务已记录等待原因，但尚未取得所需的处理位置；已有进度和成果保留。
- **成品**：已由本站保存并独立读回确认的 Word 文件；本地任务的云端成品仍需桌面回执确认落盘。
- **执行结束回执**：原凭据持有者确认自己的全部任务动作已停止的记录；这份确认不证明外部进程已由服务器终止。
- **配图任务恢复**：核对原执行结束证据和既有成果后，续接同一篇原文的配图任务；已有成果和用户的暂停或取消意图保留。
- **得到导入稿**：经本人得到流程确认最终稿和下载文件，再上传本站并提交求助小鱼的文章；它与本站自动写作稿分别核验来源。
- **配图尝试**：同一篇冻结原文采用一套素材和选图策略的处理过程；重配形成新尝试，旧成果和记录保留。
- **实际处理时间**：已取得执行权的处理时间；排队不计入，安全暂停后的停顿不计入。
- **安全停止**：原执行的动作已经全部结束，并有与该执行相符的结束证据；等待或超过时限本身不表示安全停止。
- **永久清空文章**：本人确认固定文章范围后，销毁本站原文、成品和关联正文历史，包括已绑定文章的本站得到条目、下载记录与分块文件，并撤销旧任务的本站写入；未绑定输入、得到外站、连接与订阅配置保留。防重放、额度和执行安全所需的无正文身份可以保留，外部已发动作是否结束仍以实际证据为准。
