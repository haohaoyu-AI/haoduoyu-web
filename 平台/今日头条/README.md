# 今日头条草稿助手

把「文章总库」排好的成稿自动送进**今日头条草稿箱**。程序用头条号编辑器自带的
**工具栏 → 导入文档**把 Word 读进正文（标题、小标题、正文、配图都由头条自己解析上传），
然后等头条自动保存草稿，再**另外开一个页面回读草稿箱**确认这篇真的在里面，确认成功才把原稿移入「已发文章」。

程序**没有公开发布功能**：不点「发布」，也不点「定时发布」，连预览都不点。

## 使用方法

1. 首次双击 **01-登录头条.cmd**，在弹出的专用 Edge 窗口里扫码登录头条号。看到终端显示
   「登录状态已保存」即可。这个窗口使用独立配置（`data\edge-profile`），和你日常 Edge 互不干扰，
   登录一次以后不用再扫。
2. 把成稿放进 **待发文章**。正常来源是「文章总库」：在 `项目根目录` 双击
   **09-调取到今日头条.cmd**（或 **10-分发到全部平台.cmd**）。
3. 双击 **02-保存一篇到草稿箱.cmd** 试运行；批量时双击 **03-全部保存到草稿箱.cmd**。
4. 到头条号后台「管理 → 草稿箱」检查。**已发文章**表示"已存进草稿箱"，**不代表已经公开发布**。
5. 确认无误后，在头条号后台自己设置发布时间发布（可以定时发布）。

## 和知乎、百家号不一样的地方

| | 知乎 / 百家号 | 今日头条 |
| --- | --- | --- |
| 存草稿 | 有「存草稿」按钮，程序点它 | **草稿自动保存**，程序等它保存完，再去草稿箱回读 |
| 导入文档 | 编辑器「插入 → 导入文档」 | 工具栏「**导入文档**」，支持 .docx/.pdf/.txt，单个最大 15 MB |
| 草稿地址 | 形如 `.../edit?article_id=xxx` | 草稿列表不给带 id 的地址，回执里记的是发文页地址 + 草稿箱回读证据 |

导入比较慢（每张图都要头条自己上传）。一篇 7 图的稿子大约 1 分钟，请耐心等，不要关掉专用窗口。

## 保存规则

- 核对三件事：标题一致、正文抽样一致（取 25%/50%/75%/95% 四处各 30 字）、配图数量不少于本地张数；
  三样都对上才继续等自动保存。
- 保存后**独立回读**：另开一个页面进草稿箱，确认标题出现在列表里；找不到就停下并保留原稿，
  不会当成成功。
- 标题 2～30 字；超限或为空会在写入前停下。
- 编辑器里如果已经有别的稿子（头条会自动恢复上次编辑的草稿），程序会停止；确认不要了，
  可以在命令后加 `--清空编辑器` 再运行一次（只清编辑器里的临时内容，不会删除已保存的草稿）。
- 中途失败、但结果不明时（比如已经导入、没来得及确认），程序会拒绝自动重试以免重复建稿。
  你到草稿箱人工确认确实有了之后，运行：

  ```powershell
  python -X utf8 -m toutiao_drafts resolve --标题 "标题里的一小段"
  ```

  它会补登记、写回执并把原稿归档到「已发文章」。
- 遇到登录失效、验证码或页面改版，程序会停下并保留原文；验证码和登录由你手动完成。
- 不要删除 `data` 目录，否则会丢失去重和断点记录。

## 文件和进度

| 位置 | 用途 |
| --- | --- |
| 待发文章 | 准备送进草稿箱的成稿；失败或没确认成功就留在这里 |
| 已发文章 | 已存进草稿箱并回读确认过的成稿 |
| 重复文章 | 与已处理文章内容相同的副本 |
| 预览 | 双击 `04-生成文章预览.cmd` 后生成的本地网页和清单 |
| data\drafts.sqlite3 | 状态、内容指纹、草稿地址和异常记录 |
| data\*.json | 每篇成功的回执（「文章总库」靠它把头条标成 ✅草稿箱） |
| data\edge-profile | 专用 Edge 登录状态；请勿上传、分享或删除 |
| logs | 异常截图和页面结构记录（`06-查看页面结构.cmd` 生成 `editor-probe.json`、`toolbar.html`） |

## 命令行

```powershell
python -X utf8 -m toutiao_drafts login              # 打开专用 Edge 登录一次
python -X utf8 -m toutiao_drafts list               # 看待发目录和进度
python -X utf8 -m toutiao_drafts preview            # 生成本地预览
python -X utf8 -m toutiao_drafts run --limit 1      # 送一篇进草稿箱
python -X utf8 -m toutiao_drafts run --limit 0      # 全部
python -X utf8 -m toutiao_drafts run --limit 1 --清空编辑器
python -X utf8 -m toutiao_drafts resolve --标题 "胖东来"
python -X utf8 -m toutiao_drafts probe              # 页面改版后重新记录结构
```

## 页面结构（改版后修这里）

- 发文页：`https://mp.toutiao.com/profile_v4/graphic/publish`
- 草稿箱：`https://mp.toutiao.com/profile_v4/manage/draft`（进去后要切到「草稿箱」标签）
- 标题框：`textarea[placeholder*="标题"]`（2～30 字）
- 正文区：`div.ProseMirror[contenteditable=true]`
- 导入文档：工具栏 `div.syl-toolbar-tool.doc-import button` → 弹出 `div.byte-modal.doc-import-modal`，
  里面有 `input[type=file]`（accept 含 .docx/.pdf/.txt）
- 自动保存提示：底部 `.footer-tip-save`（会显示「草稿已保存」）
- **窗口要够宽**：右侧「头条创作助手」面板会盖住工具栏右边的「导入文档」按钮，所以浏览器
  按 1600×1000 打开；如果你看到导入按钮点不到，多半是窗口被缩小了。
