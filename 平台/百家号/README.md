# 百家号草稿助手

把本地文章自动保存进百家号草稿箱。程序使用百家号编辑器自带的**「插入 → 导入文档」**把 Word 读进正文，
**Word 里的图片会一并由百家号自己上传**，不需要单独传图；保存后重新打开草稿，核对标题、正文和配图数量，
成功后将原文件移入"已发文章"。程序没有公开发布功能，不会点击"发布"或"定时发布"。

## 使用方法

1. 首次双击 **01-登录百家号.cmd**，在打开的专用 Edge 窗口里手动登录百家号。看到终端显示"登录状态已保存"即可。该窗口使用独立配置，登录状态保存在本项目中，之后无需每次重新登录。
2. 将需要发送的 `.docx`、`.md` 或 `.txt` 放入 **待发文章**。带图的成稿由「文章总库」调取进来：
   在 `项目根目录` 双击 **01-排版图文.cmd** → **03-调取到百家号.cmd**。
3. 双击 **02-保存一篇到草稿箱.cmd** 试运行；批量处理时双击 **03-全部保存到草稿箱.cmd**。
4. 去百家号后台的"内容管理 / 作品管理"里检查内容（状态为"草稿"的就是本系统存的）。**已发文章**表示"已保存到草稿箱"，并不表示已经公开发布。

本机已安装 Python 与 Playwright。换电脑时先安装 Python 3.10 或以上版本，并运行 `python -m pip install -r requirements.txt`；电脑需要安装 Microsoft Edge，不需要额外下载 Chromium。

## 图文与封面

- `.docx` 一律走百家号的「导入文档」：标题、小标题、正文、配图都由平台读进去，图片自动上传到百家号图库。
- 封面自动匹配：成稿的第一张图就是封面图（文章总库排版时会把选定封面放在正文最前面），
  导入完成后程序会打开“设置封面 → 选择封面”，直接确定使用正文第一张图；万一没点成，终端会提示你手动选一下。
- 导入完成后程序会核对三件事：标题一致、正文一致（忽略编辑器给图片加的占位说明）、正文图片数量一致，
  三样都对上才点"存草稿"。
- 导入比较慢（每张图都要平台自己上传），一篇 8 图的稿子大约 1~2 分钟，请耐心等，不要关闭专用窗口。

本机专用 Edge 已完成首次登录。2026 年 9 月 12 日已实际验证：项目根目录的 21 份 Word 全部写入百家号草稿箱，每篇都用独立页面回读标题与全文，并与后台作品列表逐条比对（本地有、列表没找到：0）。示例：

- [《绝命毒师》最后三行字，撕开了国产剧的遮羞布](https://baijiahao.baidu.com/builder/rc/edit?type=news&article_id=1876103950107830495)
- [连休13.5天让人羡慕的，是终于不用随时待命](https://baijiahao.baidu.com/builder/rc/edit?type=news&article_id=1876104845657315550)

两篇均为未公开草稿；待发目录已清空，新增文章可继续放入待发目录。

## 文件和进度

| 位置 | 用途 |
| --- | --- |
| 待发文章 | 准备送入草稿箱的原文；上传失败留在这里 |
| 已发文章 | 保存并回读验证成功的原文 |
| 重复文章 | 与已处理文章内容相同的副本，复用已有草稿 |
| 预览 | 双击 `04-生成文章预览.cmd` 后生成的本地网页和清单 |
| data/drafts.sqlite3 | 保存状态、内容指纹、草稿地址和异常记录 |
| data/*.json | 每篇保存成功的回执与草稿链接 |
| data/edge-profile | 专用 Edge 登录状态；请勿上传、分享或删除 |
| logs | 异常诊断信息、失败截图和页面结构记录 |

## 保存规则

- 支持正文段落、小标题、粗体等基础富文本格式。
- Word 里的图片会按文档顺序导入并按顺序上传；表格、公式、修订等未支持内容会明确报错，避免丢失内容后继续上传。
- Markdown 只转换标题和粗体，其他语法按原文保留；含图片的 Markdown 会报错。
- 纯文本建议用 `标题：文章标题` 标记标题，否则用文件名，正文完整保留。
- 每篇之间默认间隔 12 秒。运行期间不要在专用窗口里同时编辑文章。
- 同一份内容重复放入待发目录，不会重复新建草稿。该去重只覆盖本系统处理过的文章。
- 百家号要求标题 2-64 字。程序读取页面上标明的字数要求，超限或过短时在输入前就停止并提示，不会写入半截标题。
- 编辑器里如果已经有内容（例如百家号自动恢复了上次编辑到一半的内容），程序会停止而不是覆盖它。
  确认那些内容不要了，可以在命令后加 `--清空编辑器` 再运行一次；清空只作用于编辑器里的临时内容，不会删除已保存的草稿。
- 遇到登录失效、验证码或页面变化，程序会停止并保留原文。验证码和登录由你手动完成。
- 保存后中断、但已经记录草稿地址时，下一次会先打开同一地址核对。若只有半篇或内容不符，会保留待发文件并停止，不覆盖草稿。
- 若上传中断且没有记录到草稿地址，程序会要求先人工检查草稿箱，避免结果不明时再新建。
- 不要删除 `data` 目录，否则会丢失去重和断点记录。原文在上传过程中被修改时不会归档。

## 当前 Edge 与专用 Edge

专用窗口使用本项目自己的 `data/edge-profile`，与你的日常 Edge 互不影响，也不会读取或复制日常 Edge 的 Cookie。首次需要手动登录一次。

高级用户可通过 `--cdp http://127.0.0.1:9222` 连接已经启用本机调试的 Edge。程序不会自行关闭日常 Edge，也不会开启对外监听。有关调试连接见 [Microsoft Edge 官方文档](https://learn.microsoft.com/en-us/microsoft-edge/devtools/protocol/)。

## 页面改版怎么办

百家号后台会改版。程序不再依赖写死的 CSS 类名，而是按"可见的标题输入框 / 正文编辑区 / 存草稿按钮"来定位。如果仍然失败，双击 **06-查看页面结构.cmd**，把 `logs/editor-probe.json` 一起反馈即可修复。

已知的 2026-09 版结构：标题是 `[data-testid="news-title-input"]` 里的 contenteditable，正文是懒加载 iframe 里的 `<body class="news-editor-pc">`，"存草稿"是页头的一个普通按钮。程序只点"存草稿"，`data-testid="publish-btn"` 的"发布"按钮从不触碰。

## 命令行

在本项目目录运行：

```powershell
python -X utf8 -m baijiahao_drafts init
python -X utf8 -m baijiahao_drafts list
python -X utf8 -m baijiahao_drafts preview
python -X utf8 -m baijiahao_drafts login
python -X utf8 -m baijiahao_drafts probe
python -X utf8 -m baijiahao_drafts run --limit 1
python -X utf8 -m baijiahao_drafts run --limit 0
python -X utf8 -m baijiahao_drafts run --limit 0 --清空编辑器
python -X utf8 -m unittest discover -s tests -v
```

浏览器离线集成测试可先执行 `$env:BAIJIAHAO_BROWSER_TESTS='1'` 再运行测试命令。测试在本机 Edge 中拦截所有请求，不操作真实百家号账号。

`init` 只整理项目根目录的 Word 文件，不会把项目说明文件当成文章。`run` 默认最多保存一篇；`--limit 0` 处理全部。整个批次遇到错误会停止，不跳过错误悄悄继续。
